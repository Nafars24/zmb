# ZMB

Launcher game untuk Windows dengan dua gaya tampilan: **XMB ala PS3** dan **Coverflow ala Aurora (Xbox 360)**.

- Game PC, Steam, dan emulator (PS1, PS2, PS3 termasuk `.iso`, PSP, Vita, NES, SNES, N64, GBA, NDS, 3DS, GameCube/Wii, Mega Drive, Arcade)
- Latar & trailer game di belakang menu, musik tema game
- Trofi/achievement: Steam, RetroAchievements, RPCS3
- Unduh media otomatis (SteamGridDB, ScreenScraper), detail game, profil & statistik main
- Musik, video, foto, screensaver, tema kustom
- Update otomatis dari repositori ini

## Cara pasang
1. Download repositori ini (**Code > Download ZIP**) lalu ekstrak.
2. Klik dua kali `BUILD.bat` (memakai compiler .NET bawaan Windows 10/11, tanpa install apa pun).
3. Jalankan `ZMB.exe`.

Setelah terpasang, ZMB mengecek repositori ini dan menawarkan update sendiri (Pengaturan > Update ZMB).

Panduan lengkap: [PANDUAN.txt](PANDUAN.txt)

Data pribadi (`zmb_config.xml`, API key, daftar game) hanya tersimpan di komputer pengguna dan tidak pernah diunggah.
